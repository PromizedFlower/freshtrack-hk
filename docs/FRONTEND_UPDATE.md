# FreshTrack HK 前端设计更新说明（黄金融合方案已集成）

本更新根据「黄金融合方案」对前端视觉、交互与微动效规范进行了全面升级：

## 一、 已落地的设计更新内容

1. **燕麦再生纸色板与 OLED 深色模式 (`frontend/src/styles/tokens.css`)**：
   - 画布底色由冷灰绿升级为温暖护眼的 **燕麦再生纸色 `#F7F5F0`**，卡片面采用 **柔和米白 `#FFFEFA`** 搭配亚麻灰细边。
   - 保留三档高对比度风险徽章体系（`#991B1B` 高危红、`#92400E` 琥珀黄、`#166534` 嫩芽绿），满足 WCAG AAA 级可读性。
   - 原生支持 **`[data-theme='dark']` OLED 低碳省电模式**（`#071712` 纯黑底 + `#0F2920` 森林暗绿卡），兼顾护眼与数字环保。
   - 内置 **长辈/家政助理 125% 大字模式** 动态基准变量 `--ft-font-scale`。

2. **6 大环保多巴胺微动效库 (`frontend/src/styles/animations.css`)**：
   - `Use-by` 临期 24 小时高危食材「珊瑚红呼吸光晕 (`ft-risk-halo`)」；
   - 切换至冰箱页时的顶部「冰蓝开门冷气柔光 (`ft-fridge-door-glow`)」；
   - 超市小票上传时的「翠绿激光扫描线 (`ft-scanner-laser`)」与商品行「交错微弹渐显 (`ft-stagger-row`)」；
   - 拖拽投料进汤锅时的「Q 弹缩放与蒸汽浮动 (`ft-pot-active`)」；
   - 原生支持系统级 `prefers-reduced-motion` 无障碍减弱动画兜底。

3. **双端原型与文档归档**：
   - `prototypes/` 目录保留完整的单文件双端高保真交互原型；
   - `docs/` 目录附带全套 PRD、API 契约、选型分析及前端待办清单。

---

## 二、 极简单手操作与空间层架交互规范

- **首屏聚焦**：仅展示「今日优先抢救三件事」大卡，2 秒锁定今晚最佳减废晚餐；
- **单手闪电手势**：食材卡支持 **向右轻滑（核销吃完 +减废）** 与 **向左轻滑（移入冷冻 +30天）**，操作步数缩短至 1 步；
- **真冰箱空间层架**：`My Fridge` 支持一键切换【冷藏即食 (4°C) / 果蔬抽屉 (6°C) / 冷冻室 (-18°C)】三温区抽屉视图。
